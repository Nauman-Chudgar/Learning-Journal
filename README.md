# My Learning Journal

A responsive blog website where I document my journey as I learn frontend development. The site gives me a place to share what I’m learning, reflect on new concepts, and encourage other learners along the way.

## About the Project

I enjoy learning new frontend skills and putting them into practice through small projects. As I studied topics such as JavaScript and responsive design, I began collecting notes and sharing what I learned in my own words.

This learning journal grew from that habit. It features posts about my learning process, the ideas I discover, and the projects I build as I develop my skills.

## Features

- A homepage for browsing blog posts
- Post cards with a photo, date, title, and short description
- A clean, readable layout
- Responsive design for desktop, tablet, and mobile screens
- Content focused on frontend development and lifelong learning

## Technologies Used

- **HTML5** — structures the pages and blog content
- **CSS3** — styles the site and creates the responsive layouts
- **JavaScript** — adds interactivity to the website

## Responsive Design

The website is designed to work across different screen sizes. Its layout adjusts so the content remains easy to read and navigate on phones, tablets, and desktop computers.

I’m learning to consider responsive behavior from the beginning of a project, rather than treating it as a final step. This helps me make design choices that work well across devices.

## Getting Started

To view the project on your computer:

1. Download or clone the project files.
2. Open the project folder.
3. Open `index.html` in a web browser.

No extra setup is needed for the basic version of the site.
